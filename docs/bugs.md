# Retail bugs

Every bug of the original the port knows about, and what the port does with it. The rule (AGENTS.md, "Retail
bugs"): fix it, unless it shapes the numbers players know and play by (a gun's damage, a rate of fire, reach, jump
height and air time, the AI's aim, rolls and routes, prices and rewards); either way, list it here. Open questions and
small follow-ups go into `docs/backlog.md` as task lines; "UNKNOWN" marked a row kept as read but not confirmed
against the running original; with no emulator runs, the last of them were settled from the decomp's code and data on
2026-11-12 (owner: follow the decomp where it reads clearly, else decide and log the reasoning here), and none is left.

Sources: the decomp's `docs/port/*.md` bug lists (ai.md, battle.md, weapons.md, effects.md, cameras.md, parts.md,
screens.md, audio.md, progression.md, architecture.md, render.md), `docs/findings.md`, and the port's own sixty.md,
story.md, input.md and movies.md (sixty.md and story.md were written under the old "keep retail bugs" rule and are
re-judged here). Behaviour that is odd but meant (free play's endless ammo, the AI's lower durability floors, teams
that never fight each other) isn't listed. Most rows were read in matched code, not run; "read" marks the ones the
decomp flags as unconfirmed.

Columns: what retail does wrong; the decomp function and address; what the port does (fixes, keeps)
and where, if the code exists yet; why.
